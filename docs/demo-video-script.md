# BuyWise AI - demo video script (under 3:00)

Record at 1440×900 or larger, browser zoom 100%, dark mode. Start signed out on the welcome screen.
Before recording: run one practice conversation so Gemini is warm, and have your PayPal **sandbox** buyer login ready.
Say "PayPal" and "Gemini" out loud - the organisers ask that PayPal and AI are impossible to miss.

| Time | On screen | Say (voice-over) |
|---|---|---|
| 0:00-0:12 | Welcome screen | "Most shopping assistants just find the product you named. BuyWise finds the best thing for *you* to buy, what it really costs, and whether it fits your salary - then PayPal handles the payment." |
| 0:12-0:30 | Click **Continue with PayPal** → sandbox sign-in → back in the app → **create PIN** | "I sign in with PayPal - no new password. PayPal gives BuyWise my name and country, and I set a private PIN that approves every purchase. The AI never sees it." |
| 0:30-0:45 | Type **"I want a PS5"** → agent asks salary only | "I just say what I want. Because PayPal already told it my country, the Gemini agent only asks my salary." |
| 0:45-1:10 | Type **"60,000 rupees a month"** → point at the live status line and activity feed | "Now it works on its own: it converts my salary at today's rate, searches products, finds what else I'd need - a game, PlayStation Plus - and builds complete options, including ones I didn't ask for." |
| 1:10-1:40 | Dashboard: recommendation, **You asked vs BuyWise recommends** card, KPI tiles in ₹, AG Grid comparison (hover a score), AG Charts | "Everything is in rupees. This card compares what I asked for with what it recommends - in money. The AG Grid comparison shows pay-today, monthly and true first-year cost, and how each one fits my salary. A deterministic engine does the maths and the ranking - not the AI." |
| 1:40-1:55 | "Everything you'd buy" grid → untick an item → totals change | "I can drop anything I don't want - every total and the ranking recalculate instantly." |
| 1:55-2:15 | Click **Buy** → review → **Lock this purchase** (hash appears) | "When I'm ready, BuyWise locks the exact items and amounts into a hash-locked transaction. After this, nothing - including the AI - can change what I'm approving." |
| 2:15-2:35 | Enter **PIN** → "Authorised · PayPal order …" → PayPal button → sandbox approval | "My PIN authorises it, the backend creates the PayPal order from the locked plan using PayPal's Agent Toolkit, and I approve in PayPal." |
| 2:35-2:50 | Receipt: order id, capture id, lock hash | "Captured. The AI planned the purchase; PayPal executed it - and the AI never had the power to move money." |
| 2:50-3:00 | Back to dashboard / logo | "BuyWise AI: tell it what you want to buy - it finds what's right for you, and PayPal makes it happen." |

## Tips
- Keep chat replies on screen just long enough to read the first line; the dashboard carries the detail.
- If a request is slow, cut the wait in editing - don't speed up the payment steps.
- Upload to YouTube as **Public**, no copyrighted music, and paste the link into the Devpost form.
